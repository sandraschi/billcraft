# billcraft v0.1.0

Austrian invoices and SEPA batches. Not a Registrierkasse. Local, one SQLite file. Windows x64.

## Downloads

- `billcraft-app.exe`: the desktop window.
- `billcraft.exe`: CLI and MCP server.
- `billcraft-0.1.0-setup.exe`: per-user installer.
- `billcraft-v0.1.0.mcpb`: MCP bundle.

## What is new

- `export_xrechnung` writes the seller, buyer, payment account, tax breakdown, and lines for XRechnung 3.0.2. A store fixture was accepted by KoSIT Validator 1.6.3.
- The window menu is File, Edit, View, Window, and Help.
